Posting history across all platforms. Read before each social run to avoid repeating topics; appended to after each run. Use the SCHEDULED date, not the run date. Newest at the bottom.

Format: `- YYYY-MM-DD | platform(x|ig|fb|tiktok) | category | provider-action-id | full post text`

Scheduled posts put the adapter, provider reference and state in the provider field, for example `post-bridge:98765 [scheduled, unverified]`, and change the marker to `[published <url>]` once verified. See the post scheduling procedure in the shared workflow.
