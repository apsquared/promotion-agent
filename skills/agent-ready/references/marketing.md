# Promoting the agent use case

Being usable by agents is also a distribution channel. This file gives the angles; hand the drafting to the marketing skills available in the session (copywriting, content strategy, a social or community skill, or promotion-agent's `promote` workflow) rather than writing campaigns here. Every post, message and PR to someone else's repo is an external action that needs its own approval.

Figures below are Nevo David's own reports about Postiz, cited as his claims. Do not promise them to the user or reuse them as the product's numbers.

## Why it travels

- **New demand with little supply.** Nevo: Postiz took 18 months to reach about $21K MRR as a classic scheduler, then about $103K within roughly two months of becoming agent-ready (LangTalks ep. 69). He also reports monthly churn falling from 26–28% to 13.7% after the agentic pivot (Starter Story, 30 Jul 2026).
- **Interest-matched feeds.** X matches posts to people interested in a topic right now rather than to followers, and agents are a constant topic there, so content about an agent use case can travel from a small account (LangTalks ep. 69; notJust.dev, 22 Sep 2026).
- **Marketplaces recommend what gets installed.** After about 1.2M downloads from Claude's marketplace, Claude began recommending Postiz on its own (LangTalks ep. 69).

## Content angles

1. **Outcome-led posts and articles** about what an agent can now do with the product: "My agent now does X every morning", with a real workflow and proof. Sell the outcome, not the tool (notJust.dev, 22 Sep 2026). Nevo describes reusing one use case for each new agent (OpenClaw, Hermes, a new Claude release) with only the agent's name changed.
2. **Ship the workflow as a skill.** A skill that packages the whole workflow converted better than a step-by-step article for Postiz ("How OpenClaw Skills and X Articles Grew Postiz from $20K to $60K MRR", 16 Mar 2026).
3. **"I built an X node / skill" posts** in the communities where builders gather: Skool and Whop groups, Discord servers, subreddits such as r/n8n. Share a useful workflow that uses several tools rather than a pitch (Alex is Building interview, 20 Jul 2026).
4. **SEO pages about using the product with agents**, the last step in Nevo's readiness order ("Postiz by stage", 13 Jul 2026). Each page needs a working install line and claims from the docs.

## Get into other people's workflows

- Ship integrations where builders already work: an n8n node or templates, Zapier or Make. Nevo describes generating an n8n node from the public API in about an hour (X posts, Nov 2025).
- Ask template and course authors to include the product. Offer something worth more to them than to you: a free top plan, a newsletter feature, introductions, a backlink. He reports about 80% replies and many new templates from n8n Skool group owners (Alex is Building interview).
- Draft the outreach list and messages for the user to review and send. Never send automatically, never scrape personal contact data without the user's decision, and follow each community's rules.

## Build around a hype, don't be the hype

Watch for the next wave (n8n, then MCP, then agents, then whatever comes next) and be early with a surface for it. Nevo: a product that is itself the hype can lose it when the hype passes; build the surface before the trend, then wait for it ("Postiz by stage"; Starter Story).

## Measure

To check whether assistants now recommend the product, use promotion-agent's AI visibility activity (`promotion-visibility`) for a baseline before listing and a re-measure afterwards. Track installs and listing views where each directory shows them, and trials or signups attributed to agent surfaces where the product can tell.
