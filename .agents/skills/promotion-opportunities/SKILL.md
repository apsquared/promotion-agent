Read [the shared workflow](../../../templates/WORKFLOW.md), then follow [promotion opportunity qualification](../../../templates/activities/promotion-opportunities/WORKFLOW.md). Use activity `directory` for research and existing categories for follow-up actions.

Resolve the named product through the shared discovery procedure. Keep its source repository read only and save evidence, kits and tasks in its selected separate promotion workspace; an unregistered request can return research in chat. Use this session's research tools yourself.

Only recommend candidates that pass the procedure's quality, traffic-or-SEO value and live availability/eligibility gates. Missing evidence leaves a candidate off the shortlist. Recheck before a later action. A research request authorizes preparation, not submission, outreach, accounts or spending; follow the shared workflow for authorization and evidence.
